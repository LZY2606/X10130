# 消息目录校验工作台（Message Catalog Validation Workbench）

本地 Go 服务，无外部数据库、无外部网络依赖。导入基准语言和目标语言的 ICU 消息目录后，
可以发现缺项、多项、占位符集合不一致、占位符类型漂移、复数类别缺失、富文本标签不平衡，
并支持带期限的问题豁免、基准改名确认、逐语言批量修正、一致性快照语义和可机器读取、
字节确定的发布证明。所有数据保存在本地目录，重启后版本、原始文件、改名映射、豁免、
批量结果、幂等操作记录和证明都在。

## 准备与演示

```bash
go build ./...
go test ./... -count=1
go run ./cmd/server --addr 127.0.0.1:5216
```

浏览器打开 http://127.0.0.1:5216 ，页面标题为“消息目录校验”。

可选参数：

- `-data <dir>`：本地数据目录，默认 `.catalog-data`。
- `-start-time <RFC3339>`：使用受控时钟启动（演示豁免到期）。运行期也可通过
  `POST /api/admin/clock` 用 `{"set": "..."}` 或 `{"add": "720h"}` 调整。

页面上点击“一键载入演示数据”即可获得包含全部问题类型的 zh/ja/fr 样例。

## 90 秒浏览器演示路径

1. 点击“一键载入演示数据”，在问题列表看到缺项/多项/占位符/复数/标签问题。
2. 对某条问题点击“豁免…”，填写理由和天数；再点“时钟快进 31 天”，豁免变为过期，
   未豁免计数恢复。
3. 在批量修正区点击“携带过期版本期望提交（冲突演示）”：一种语言冲突、另一种语言成功，
   其余语言不回滚；用同一操作标识再次提交会重放既有逐语言回执，不产生新版本。
4. 点击“先改 ja 再重试（部分成功+冲突）”可观察已成功语言保持成功、重试只处理未完成项。
5. 相同操作标识重复导入/确认改名/豁免/生成证明时版本数不增加；改同一标识的内容会收到
   明确的 409 冲突。
6. 生成发布证明并预览；页面上问题视图、并排视图、证明均显示同一 `snap-…` 状态标识。
   失效结果不能生成“最新”证明，旧证明标记为历史状态但仍可下载。

## 设计要点

- 内容指纹：对键排序、换行归一化（CRLF/CR→LF）后取 SHA-256；仅改变键顺序或换行风格
  不产生新版本。每次上传的原始字节以内容寻址 blob 保存，可逐字节下载。
- 原子持久化：状态文件为带 SHA-256 校验和的信封，写入走临时文件 + rename，并保留
  `state.prev.json`。启动时当前文件损坏会隔离到 `quarantine/` 并回退到上一份完整快照，
  进入只读降级模式并显式报告；引用的原文/证明 blob 缺失或校验不符时同样只读。
- 改名映射：仅保存使用者显式确认的“旧 key→新 key”边；拒绝成环、拒绝把两个旧 key
  并入一个新 key；确认操作校验基准版本和映射状态，过期视图返回冲突。
- 幂等：所有改变状态的接口接受 `Idempotency-Key`（也可用 `?opId=`），同标识+同内容
  返回既有结果，同标识+异内容返回 409。批量结果按语言持久化，部分成功后的重试只处理
  尚未成功的语言。
- 快照语义：问题列表、并排视图、结果重放、证明都携带 `snap-…` 与解析器版本；读取对应
  单一已提交状态。校验结果不可变，基准/映射/解析器变化只失效受影响结果，历史结果可
  固定重放且显式标记失效；失效结果不能生成当前证明。
- 发布证明：确定性 JSON（固定字段顺序、无 HTML 转义），包含输入指纹、未豁免问题计数、
  每个豁免的理由与期限、解析器版本与快照标识；相同逻辑状态与期限判定下字节一致。
  证明写入走临时文件 + rename，中断后不暴露截断文件，上一份完整证明仍可读。

## 主要 HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/import` | multipart 上传目录（`language`,`role`,`file`） |
| POST | `/api/import-json` | JSON 形式导入（测试/脚本） |
| POST | `/api/demo/seed` | 载入内置演示数据 |
| GET | `/api/uploads`、`/api/uploads/{id}/raw` | 上传列表、逐字节原文下载 |
| GET | `/api/versions` | 所有内容版本 |
| GET | `/api/compare?key=...` | 某 key 各语言原始文本与解析结构 |
| GET | `/api/rename-candidates`、`POST /api/renames/confirm` | 改名候选与确认 |
| GET | `/api/validations`、`/api/validations/{id}` | 当前问题与固定结果重放 |
| POST/GET | `/api/exemptions`、`POST /api/exemptions/{id}/revoke` | 豁免管理 |
| POST | `/api/batch-fix`、`GET /api/batches` | 逐语言批量修正与回执 |
| POST/GET | `/api/proofs`、`/api/proofs/{id}/raw` | 生成、列出、下载发布证明 |
| POST | `/api/admin/clock` | 受控时钟 |

所有写接口支持 `Idempotency-Key` 请求头。冲突统一返回 HTTP 409 与
`{"conflict":true,...}`；只读恢复模式返回 503。

## 测试

`go test ./... -count=1` 覆盖：ICU 单引号规则、复数类别、嵌套/自闭合标签、换行归一化、
改名环与二并一拒绝、同标识重放与异内容冲突、批量部分成功与逐语言重试、豁免到期、
证明确定性与快照冲突、选择性失效、以及当前状态损坏回退、临时文件清理、blob 校验、
重启后幂等重放等崩溃恢复场景。
